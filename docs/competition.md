# 대회 개요

굿퀘스천 MVP를 제출하는 해커톤의 공고 내용이다.
출처: [Blaybus 활동 공고](https://www.blaybus.com/activities/928/landing)

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 대회명 | 2026 스타트업 영그라운드 MVP 개발 해커톤 |
| 주최·주관 | 어치브모먼트(Blaybus), 강동구 청년해냄센터 |
| 주제 | 실제 창업 아이템 기획서 기반 웹/앱버전 MVP 구현 |
| 참가 자격 | 실전 창업 아이템 구현 및 창업 팀과의 협업에 관심 있는 누구나 (고등학생 이상의 청년) |
| 참가 단위 | 개인 또는 팀 단위, 최대 100명 |
| 우리 팀 | 해커톤오이쉬 (프론트엔드 1 · 백엔드 1 · AI 1) |
| 배정 아이템 | 굿퀘스천 (Good Question) |

| 2026-08-20 | 최종 발표 (파이널 데이) |

## 제출물

- 서비스 구동 URL
- 발표자료

주최측은 테스트 데이에 **사용자 매뉴얼**을 추가 제출할 수 있다고 안내했다.
(PRD 3.3 · 11.3 O-17 참조)

## 발표 유의사항

- 파이널데이 행사만 서울에서 진행한다.
- 현장 PT 및 시연부스 운영을 위해 필수 참석이며, 팀의 경우 **팀 내 최소 3명 이상 참석**해야 한다.

## 혜택

- 파이널 최종발표 우수팀 총상금 240만원
- 입주기업 지원 시 가산점 부여
- IT 직군 개발자 협업 기회 제공

## 심사 기준

공고에 별도 명시되어 있지 않다. 다만 주최측이 추가 요건에 대해 다음을 안내했다.

- 보호자 리포트는 선택 요건이나, **각 영역의 완성도와 구성 영역 개수에 따라 평가**한다.
  (`docs/reference/guardian-report-guide.md` 2절 참조)
