# 이야기 이미지 에셋 요청 — 그림체 재작업 + 캐릭터·표지 신규 생성

- **요청자**: 백엔드 담당
- **작성일**: 2026-08-13
- **우선순위**: 필수

## 배경

주최측이 도입·전개·대화·미션 장면 이미지를 이미 제공했지만, 그림체가 서비스 톤과 맞지
않아 재작업이 필요합니다. **장면 구성(피사체·구도·컷 수)은 그대로 두고 그림체만
새로 바꿉니다.** 원본은 레퍼런스로 별도 전달합니다.

추가로 아직 없는 캐릭터 이미지·이야기 표지 이미지가 필요하고, **대화 중 캐릭터
이미지가 상태(표정)에 따라 바뀌는 기능**을 위해 캐릭터별 상태 이미지도 여러 장
필요합니다. 이 상태값은 AI가 그때그때 생성하는 대사 내용에 맞춰 직접 판단해서
응답에 함께 내려주는 새 필드로 받습니다 — 자세한 내용은 3번 항목 참고.

말하기 후 활동 카드 이미지(4장)는 전개 배경 4장에서 코드로 크롭해서 씁니다
([docs/spec/assets.md §2-5](../../spec/assets.md)) — **이번 요청 범위에서 제외**합니다.
아이 프로필 아바타도 이미 있어 제외합니다.

> 참고: [docs/spec/assets.md](../../spec/assets.md)는 2026-08-10 작성 시점 기준 "전부 미수령"
> 전제로 규격만 제안해 둔 문서입니다. 이후 도입·전개·대화·미션 이미지는 실제로 수령했으므로
> 그 문서의 수령 상태 표는 낡았습니다 — 규격 제안(치수·비율)만 참고하고, 수령 여부는 이
> 문서를 기준으로 삼아 주세요.

## 요구사항

### 1. 도입·전개·대화·미션 이미지 — 그림체만 교체, 구성은 유지

주최측 원본을 레�퍼런스로 첨부합니다. **같은 장면·같은 구도**를 새 그림체로 다시
그려주세요. 장면을 새로 해석하거나 구도를 바꾸지 않습니다.

- 새 그림체 방향(팔레트·선화 스타일 등 무드보드)은 확정되는 대로 이 문서에 추가합니다.

### 2. 캐릭터 초상 — 신규 3장

등장 캐릭터 3명, 원형 마스크용 정면 초상:

| 캐릭터 코드 | 이름 | 비고 |
| --- | --- | --- |
| `ch_banggui_daughter_in_law` | 며느리 | 장면 3·9 등장 |
| `ch_banggui_father_in_law` | 시아버지 | 장면 5 등장 |
| `ch_banggui_village_chief` | 마을 이장 | 장면 7 등장 |

### 3. 캐릭터 상태(표정)별 이미지 — 신규, AI 응답 필드 추가 필요

대화 중 캐릭터 이미지를 상태에 따라 바꾸는 기능입니다. **상태 판단은 AI가 합니다** —
백엔드가 발화 성격으로 미리 분류해 둔 값(`reactionKey` 등)을 그대로 쓰지 않고, AI가
실제로 생성한 대사 내용에 맞는 상태를 스스로 골라 응답에 함께 내려줍니다. 사전에
분류된 입력값과 실제 생성 문장의 뉘앙스가 어긋날 수 있기 때문입니다.

**상태값 (5종, 고정 — 모든 캐릭터 공통)**

| 상태값 | 의미 |
| --- | --- |
| `NEUTRAL` | 평온함, 기본 상태 |
| `HAPPY` | 기쁨, 웃음 |
| `WORRIED` | 걱정, 곤란함 |
| `SURPRISED` | 놀람 |
| `MOVED` | 감동, 뭉클함 |

캐릭터 3명 × 상태 5종 = **이미지 15장**.

**AI 응답 필드**: 캐릭터 대사를 생성하는 응답(현재 `{ "text": "..." }` 형태)에
`characterState`를 추가해주세요.

```json
{ "text": "그랬구나, 네 말을 들으니 마음이 좀 놓이는구나.", "characterState": "MOVED" }
```

- `characterState`는 위 5개 값 중 하나이며 항상 포함됩니다.
- 장면을 마무리하는 `CLOSING` 대사는 AI가 생성하지 않고 백엔드가 미리 검수해 둔
  고정 문구를 사용하므로, 이 필드는 **대화 중(NORMAL/GUIDED) 응답에만** 해당합니다.

### 4. 이야기 표지 이미지 — 신규 1장

1장으로 통일하고, 화면별 비율 차이는 백엔드/프론트 코드에서 크롭해서 처리합니다.

## 출력 (파일 규격)

| 항목 | 수량 | 규격 | 형식 |
| --- | --- | --- | --- |
| 도입·전개 배경 (재작업) | 5장 | 1280×800 (16:10), 좌측 768×800이 세이프 에어리어 | WebP, 300KB 이하 |
| 대화 장면 (재작업, 있는 경우) | 제공 원본 수량대로 | 배경과 동일 규격 | WebP |
| 미션 삽화 (재작업, 있는 경우) | 제공 원본 수량대로 | 표시 위치별 원본 비율 유지 | WebP/PNG |
| 캐릭터 초상 | 3장 | 320×320 정사각, 투명 배경 | PNG |
| 캐릭터 상태별 이미지 | 15장 (3명 × 5상태) | 320×320 정사각, 투명 배경 | PNG |
| 이야기 표지 | 1장 | 1440×1080 (4:3) | WebP |

파일명 규칙: `sc_banggui_{장면번호}` (배경), `ch_banggui_{캐릭터코드}` (초상),
`ch_banggui_{캐릭터코드}_{상태값}` (상태별), `cover_banggui` (표지) — 제안값이며
확정 시 이 표를 갱신합니다.

## 품질 기준

- 캐릭터별 상태 5종은 서로 확실히 구분되는 표정이어야 합니다 (아이가 봤을 때 감정이
  명확히 읽혀야 함)
- 같은 캐릭터는 상태가 달라져도 동일 인물로 인식 가능해야 합니다 (헤어·의상·색감 고정)
- 재작업본은 원본과 같은 장면임을 알아볼 수 있어야 합니다 (구성·구도 유지, 그림체만 교체)

## 제약 조건

- 응답 시간: 이미지 자체는 런타임 생성이 아니라 사전 제작 정적 에셋이므로 해당 없음.
  `characterState` 필드는 `/respond`의 요청 전체 10초·최초 포함 최대 3회 정책을 따른다.
- 비용/토큰 한도, 사용 모델 제약: AI 파트에서 확인 후 채워주세요.
