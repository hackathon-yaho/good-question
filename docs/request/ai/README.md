# AI 파트 요구사항

AI 파트에 요청하는 사항을 문서로 남기는 폴더입니다.
모델 선택, 프롬프트, 입출력 형식, 평가 기준 등이 여기에 해당합니다.

## 이런 걸 요청합니다

- 특정 입력에 대해 어떤 결과를 만들어 달라 (생성, 분류, 요약, 평가 등)
- 출력 JSON 스키마 정의
- 프롬프트 수정 / 품질 개선
- 응답 속도·비용 제약 조정
