# `/respond` 최대 100자 대사 표시 확인 요청

- **요청자**: AI 파트
- **작성일**: 2026-08-15
- **우선순위**: 필수

## 배경

AI 구조화 출력의 44자 상한이 문장 중간 절단을 일으켰습니다. AI 서버는 완결된 한 문장을 우선하기 위해 `/respond.text`의 기술적 상한을 100자로 조정했습니다. 실제 생성 목표는 기존처럼 32~36자이며, 100자는 예외적인 긴 완결 문장을 위한 안전 상한입니다.

## 요청사항

- 대화 화면이 공백 포함 최대 100자의 한국어 한 문장을 CSS 또는 클라이언트 코드에서 자르지 않고 표시하는지 확인해 주세요.
- 줄바꿈으로 표시되는 것은 허용하지만, 문장 전체가 보이고 재생 버튼이 가려지지 않아야 합니다.
- TTS 요청에는 화면에 표시한 것과 같은 전체 문장을 전달해 주세요.
- 이 요청은 API 필드 추가나 프론트엔드 문구 변경을 요구하지 않습니다.

## 계약

- 대상: `POST /respond`의 `text`
- 제약: 공백 포함 최대 100자, 줄바꿈 없음, `.`, `?`, `!` 중 하나로 끝나는 한 문장
- 생성 목표: 32~36자
- 정본: [AI 서버 연동 v1](../backend/ai-service-integration-v1.md)

## 완료 조건

- [ ] 최대 100자 대사를 대화 화면에서 문장 중간 절단 없이 확인했다.
- [ ] 해당 대사를 재생해도 표시 문장과 TTS 입력이 동일하다.
