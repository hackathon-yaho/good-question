# 장면별 추천 단어 카드 표시 요청 v2

- **요청자**: AI 파트
- **작성일**: 2026-08-16
- **우선순위**: 필수
- **대상**: 프론트엔드 파트

## 배경

배포 테스트에서 장면 3의 캐릭터 대사에 `이상하게`가 들어갈 때마다 그 단어만 밑줄로
보였다. 이는 AI가 매번 같은 단어를 추천한 것이 아니다. 백엔드의 기존 `highlightWords`가
장면별 고정 후보를 대사 안에서 찾으면 밑줄을 넣는 구조이기 때문이다.

8세 이하 아동에게 보여 줄 학습 단어는 이미 메시지 응답의 `recommendedWord`로 분리되어
있지만, 현재 프론트 타입·화면에는 연결되지 않아 보이지 않는다. 대화의 자연스러움과 단어
학습을 분리하기 위해 이 문서는 [v1](scene-vocabulary-card.md)을 대체한다.

## API 계약

`POST /api/sessions/{sessionId}/messages` 성공 응답에 이미 포함되어 있다.

```json
{
  "recommendedWord": {
    "word": "탐스러운",
    "meaning": "먹음직스럽고 보기 좋은 모습"
  },
  "highlightWords": []
}
```

- `recommendedWord`는 `{ word: string, meaning: string } | null`이다.
- `highlightWords`는 하위 호환을 위해 당분간 응답에 남지만, 이 MVP의 대화 대사에는
  밑줄·팝업으로 표시하지 않는다.
- `recommendedWord`가 없는 장면은 카드도 표시하지 않는다.

## 요구사항

1. 프론트 API 타입과 플레이 상태에 `recommendedWord`를 반영한다.
2. `recommendedWord`가 있을 때만 캐릭터 대사 아래에 작은 **오늘의 단어** 카드를 하나
   표시한다. 단어와 쉬운 뜻을 보여 준다.
3. 카드를 누르면 기존 단어 팝업·`POST /api/wordbook` 저장 흐름을 재사용한다.
   `word`, `meaning`, 현재 `sourceSceneId`, 현재 캐릭터 대사를 그대로 사용한다.
4. 이 카드가 적용되면 대사 본문의 `highlightWords` 밑줄 및 해당 탭 동작은 렌더링하지
   않는다. AI 대사가 학습 단어를 억지로 포함할 필요가 없어지고, `이상하게` 같은 우연한
   단어만 강조되는 문제가 사라진다.
5. 새 전역 상태·새 DB·새 API·LLM 호출을 만들지 않는다. 같은 장면에서 여러 턴이 있어도
   같은 카드가 반복되어 쌓이지 않게 한다.

## 완료 조건

- [ ] 장면 3에서 `이상하게`가 대사에 있어도 밑줄이 생기지 않는다.
- [ ] `recommendedWord`가 있는 장면에는 단어·쉬운 뜻 카드가 하나만 보인다.
- [ ] 카드를 눌러 단어장에 저장할 수 있고, 저장 뒤 중복 저장 버튼은 완료 상태가 된다.
- [ ] `recommendedWord: null`인 장면은 카드·빈 영역·오류가 없다.
- [ ] 메시지·STT·TTS·미션 흐름에 변경이 없다.
