# 도입부 텍스트 길이 요청 — 반려 (자문위원 검수 완료 텍스트라 확장 불가)

- **요청자**: 백엔드 담당
- **작성일**: 2026-08-13
- **우선순위**: 정보 공유

## 배경

[request/backend/star-dust-exposure.md](../backend/star-dust-exposure.md)의 "함께 요청 —
도입부(intro) 텍스트 길이" 항목에 대한 회신입니다. C-1 도입부를 3문장에서 4~6문장으로
늘려달라는 요청이었는데, 백엔드에서 문장을 새로 쓰는 방식으로는 처리하지 않기로 했습니다.

## 왜 늘릴 수 없나

도입부 `scene_description`은 주최측이 제공하고 **자문위원 난이도 검수까지 끝낸 고정
텍스트**입니다([PRD 7.4](../../product/prd.md)). 이 프로젝트에서 검수 완료 텍스트를
수정한 유일한 선례(전개2)도 팀이 문장을 늘린 게 아니라, 주최측이 이미 제공한 두 버전
중 하나를 정본으로 택한 경우였습니다. 도입부는 그런 대체 버전이 없어서, 4~6문장으로
늘리려면 팀이 없는 문장을 새로 창작해야 합니다 — 검수를 거치지 않은 문장이 검수 완료
텍스트 사이에 섞이는 셈이라 임의로 하지 않기로 했습니다.

## 그래서 어떻게 할까요

`GET /api/sessions/{sessionId}`의 도입부 텍스트는 **3문장 그대로** 나갑니다. "3번 눌러보면
바로 끝난다"는 체감 페이싱 문제는 프론트 쪽에서 UI로 흡수해주시면 좋겠습니다. 예를 들어:

- 문장 하나를 여러 번(타이핑 애니메이션 등)에 걸쳐 천천히 보여주기
- 도입부 화면에 최소 노출 시간이나 자동 진행 딜레이를 둬서 "다음"을 눌러도 바로 안 넘어가게 하기
- 3문장을 그대로 쓰되 화면 전환에 여백(장면 전환 연출 등)을 추가해 체감 턴 수를 늘리기

구체적인 방식은 프론트 판단에 맡깁니다. 이후 주최측에 문장 추가가 가능한지 확인되면
그때 다시 반영하겠습니다.
