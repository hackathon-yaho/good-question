# 프론트엔드 통합 테스트 수정 요청 (2026-08-15)

- **요청자**: AI 파트
- **작성일**: 2026-08-15
- **우선순위**: 필수

## 배경

최신 `main`을 기준으로 로컬 PostgreSQL·백엔드·AI 서버·프론트를 함께 기동해 자동 검증과
실서버 대화 1턴을 확인했습니다. API 경로·본문 배선은 통과했지만, 프론트 프로덕션 빌드와
미션·마이크·백엔드 음성 UI에서 재현 가능한 결함이 확인됐습니다.

이 요청은 **프론트 화면·상태 처리만** 대상으로 합니다. 백엔드 API 계약이나 AI 서버 동작을
바꾸지 않습니다.

## 화면 / 경로

| 화면명 | 경로 | 확인된 문제 |
| --- | --- | --- |
| C 대화 | `/play/{sessionId}` | 프로덕션 TypeScript 빌드 실패, C-4 안내문 정렬, 마이크 허용 후 전환 |
| C-10 미션1 | `/play/{sessionId}` | 현재·완료 체크리스트 상태와 한글 그룹명이 화면에 반영되지 않음 |
| I-1·I-3 | `/play/{sessionId}` | 마이크 허용 후 도입 전환 및 네트워크 재시도 복구 실패 |
| 백엔드 음성 모드 | `/play/{sessionId}?speech=backend` | 변환 중/변환 결과 확인 단계가 나타나지 않음 |

## 사용자 흐름

1. 아이가 C-4에서 마이크 권한을 허용하면 C-1 도입으로 즉시 이동한다.
2. 아이가 미션1의 `말해볼래요`로 발화하면, 한 항목은 완료되고 다음 한 항목만 현재 상태가 된다.
3. 백엔드 STT 요청 동안 `변환 중`을 보이고, 성공 뒤 `변환된 내 말` 확인·제출 단계로 진행한다.
4. 네트워크 오류 뒤 재시도를 누르면 실패했던 발화 요청이 한 번만 다시 실행되고 정상 대화로 복귀한다.

## 요구사항

- `npm run build`의 TypeScript 오류를 해소한다. 현재 `PlayScreen.tsx`에서 `MissionBrief`에
  전달하는 `doneCount`가 `Props`에 없다는 오류로 빌드가 실패한다.
- C-10 미션1 브리프에서 아래 상태를 모두 시각적으로 구분한다.
  - 현재 항목은 정확히 1개이며, 첫 진입 시 1번이다.
  - 완료 항목은 체크 표시와 완료 상태를 보인다.
  - 발화·서버 응답 뒤 완료 항목 수는 증가하고 현재 항목은 다음 항목으로 이동한다.
  - `지금 말해볼 것`과 선택지는 서로 다른 행에 두고, 선택지는 영문 코드가 아닌 한글 그룹명으로 보인다.
- I-1에서 권한 허용 결과를 받으면 C-1 도입 화면으로 전환한다.
- I-3 재시도는 대기만 하지 말고 이전 실패 요청을 재실행한다. 중복 제출도 만들지 않는다.
- `speech=backend`에서 STT 업로드 직후 `변환 중` 상태를 보이고, 성공 시 `변환된 내 말`
  입력/확인 단계를 노출한다. 응답 대기와 같은 문구·상태로 합치지 않는다.
- C-4 `이제 말해 볼까?` 안내문은 우측 패널의 수평 중앙에 배치한다.
- 레이아웃 검증은 240초 안에 완료돼야 한다. 미션 상태 대기나 화면 전환에서 무한 대기가 없어야 한다.

## 상태별 처리

| 상태 | 화면 처리 |
| --- | --- |
| 마이크 권한 허용 | I-1 제거 후 C-1 도입을 표시 |
| STT 변환 중 | 마이크 입력 잠금 + `변환 중` 표시 |
| STT 성공 | 변환 텍스트 표시, 아이가 확인·수정 후 제출 |
| 네트워크 재시도 | 동일 요청을 한 번만 재전송, 성공 시 기존 대화 상태로 복귀 |
| 미션 항목 완료 | 완료 체크 증가, 다음 항목 하나만 현재 표시 |

## 연동 API

| 메서드 | 경로 | 용도 |
| --- | --- | --- |
| POST | `/api/stt` | 오디오를 텍스트로 변환. 성공 후 확인 단계로 이동 |
| POST | `/api/sessions/{sessionId}/messages` | 아이가 확인한 텍스트를 제출 |
| GET | `/api/tts` | 캐릭터 대사 재생 |

API 경로·본문은 `scripts/verify/wiring.mjs`에서 37건 모두 통과했습니다. 이번 수정에서 API를
추가하거나 필드를 변경하지 않습니다.
