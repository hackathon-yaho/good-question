# 8세 이하 학습 단어 추천 데이터 요청

> **대체됨**: [실제 캐릭터 대사 기반 8세 이하 추천 단어 v2](character-utterance-vocabulary-v2.md)를
> 정본으로 사용한다. 이 문서의 장면 번호만으로 단어를 추천하는 규칙은 적용하지 않는다.

- **요청자**: AI 파트
- **작성일**: 2026-08-15
- **우선순위**: 선택

## 배경

현재 `highlightWords`는 LLM이 만든 캐릭터 대사에 장면별 후보 단어가 우연히 포함될 때만 내려간다.
후보도 `이상하게`·`창피한`·`탐스러운`·`부끄러워`로 고정되어 있으나, 8세 이하가 이야기 맥락에서
배워 보면 좋은 단어를 안정적으로 추천한다는 기준은 없다.

LLM 대사 안에 단어를 강제로 넣어 보니 문맥과 말투가 어색해지는 실제 사례가 확인됐다. 따라서
`highlightWords`는 “대사에 실제 있는 단어 밑줄” 역할로 유지하고, 추천은 AI 대사와 분리된
**오늘의 단어 카드** 데이터로 제공해야 한다.

개별 아이가 어떤 단어를 이미 아는지는 서버가 판단하지 않는다. 이 기능은 "모르는 단어"를
단정하지 않고, **8세 이하가 한 번 배워 보면 좋은 단어 1개**를 장면마다 제안하는 방식이다.

## API 명세

### `POST /sessions/{sessionId}/messages`

기존 성공 응답에 선택 필드만 추가한다. 캐릭터 대사와 문자열 일치할 필요가 없으므로
`highlightWords`와 별개다.

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `recommendedWord` | object \| null | N | 현재 대화 장면의 오늘의 단어 1개 |
| `recommendedWord.word` | string | 조건부 | 장면과 연결된 추천 단어 |
| `recommendedWord.meaning` | string | 조건부 | 초등 저학년이 이해할 쉬운 한 문장 뜻풀이 |

```json
{
  "characterMessage": "천천히 생각해도 괜찮네.",
  "highlightWords": [],
  "recommendedWord": {
    "word": "탐스러운",
    "meaning": "먹음직스럽고 보기 좋은 모습"
  }
}
```

`highlightWords`의 기존 의미와 `POST /wordbook` 저장 형식은 바꾸지 않는다.

| 대화 장면 | 제안 단어 | 쉬운 뜻풀이 | 선정 이유 |

## 데이터 모델

새 테이블·DB 컬럼은 만들지 않는다. 장면 순서별 `SceneVocabulary` 또는 기존
`HighlightWords`와 분리한 상수로 `word`·`meaning`을 관리한다.

## 제약 조건

- `recommendedWord`는 LLM 입력·출력·프롬프트에 넣지 않는다. AI 대화의 자연스러움이 우선이다.
- 단어를 아이의 정답·실력·모름으로 평가하지 않는다.
- 뜻풀이는 어려운 한자어·또 다른 미정의 어려운 단어를 피한다.
- `recommendedWord`가 `null`이어도 기존 대화·단어장 흐름은 정상이어야 한다.
- 인증·응답 시간·DB 마이그레이션 정책은 기존 메시지 API를 따른다.
