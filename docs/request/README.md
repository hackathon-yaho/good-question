# 요구사항 (request)

파트 간에 주고받는 **요청 사항과 요구사항 정의서**를 모으는 폴더입니다.
"누가 무엇을 왜 필요로 하는가"를 남겨서, 구두로 합의한 내용이 사라지지 않게 하는 것이 목적입니다.

## 폴더

| 폴더 | 요청 대상 |
| --- | --- |
| [ai/](ai/) | AI 파트 (모델, 프롬프트, 데이터) |
| [backend/](backend/) | 백엔드 파트 (API, 데이터 모델, 인프라) |
| [frontend/](frontend/) | 프론트엔드 파트 (화면, 컴포넌트, 연동) |

## 문서 작성 절차

1. 요청 대상 파트의 폴더에 새 마크다운 파일을 만듭니다.
2. 해당 폴더의 `README.md`에 있는 템플릿을 복사해 채웁니다.
3. 커밋 후 담당자에게 공유합니다.

## 파일명 규칙

```
<기능/주제>.md
```

예시: `question-generate.md`, `user-auth.md`, `result-share.md`

## 공통 필수 항목

어떤 파트에 요청하든 아래 항목은 반드시 포함합니다.

- **요청자 / 작성일** — 누구에게 물어보면 되는지
- **배경** — 왜 필요한지
- **요구사항** — 무엇이 필요한지 (목록으로)
- **완료 조건** — 무엇이 되면 끝난 것인지
- **우선순위** — `필수` / `선택`
