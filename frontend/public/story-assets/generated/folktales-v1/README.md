## 사용 제약

- 표지는 이야기 목록·상세의 배경 후보이며, 문자 가독성을 위해 UI에서 필요한 여백·그라데이션을 별도로 적용한다.
- 인물 카드는 `NEUTRAL` 상태의 기준 이미지다. 이야기 진행 상태별 표정 이미지는 별도 자산으로 추가한다.
- 지금은 **자산 추가만** 한다. 스토리 ID·DB·프론트 카탈로그·AI 프롬프트에는 연결하지 않는다.
